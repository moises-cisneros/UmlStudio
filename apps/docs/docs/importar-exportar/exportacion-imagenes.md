# Exportación como Imagen PNG de Alta Resolución

UmlStudio permite exportar cualquier diagrama de clases a formato gráfico PNG nítido, ideal para documentación técnica, presentaciones, artículos o wikis de ingeniería.

---

## Opciones de Escala y Calidad

Al desplegar el menú **Exportar > Exportar como PNG**, puedes elegir entre tres niveles de resolución:

- **1x (Resolución Estándar)**: Adecuada para previsualización rápida o inserción en mensajes de chat y correo.
- **2x (Alta Definición / Retina)**: Resolución recomendada para documentos técnicos, especificaciones y pantallas de alta densidad.
- **4x (Ultra HD / Calidad de Impresión)**: Máxima nitidez para posters arquitectónicos o impresión física en gran formato.

---

## Opciones de Composición

- **Fondo Transparente o Sólido**: Puedes alternar si deseas conservar el color de fondo del tema actual o exportar una imagen transparente recortada exactamente a la caja delimitadora (_bounding box_) del diagrama.
- **Exclusión de Guías y Controles**: Las líneas de ayuda, cursores multiusuario y cajas de selección se ocultan automáticamente durante la captura para generar una imagen limpia del modelo.
