# Catálogo Completo de Atajos de Teclado

Los atajos de teclado en UmlStudio están diseñados para permitirte modelar y navegar a velocidad de pensamiento, reduciendo la dependencia del ratón.

:::tip Nota para usuarios de macOS
En sistemas macOS, sustituye la tecla <kbd>Ctrl</kbd> por <kbd>Cmd</kbd> (o <kbd>⌘</kbd>) y <kbd>Alt</kbd> por <kbd>Option</kbd> (o <kbd>⌥</kbd>).
:::

---

## 1. Archivo y Gestión del Diagrama

| Acción                              | Atajo (Windows / Linux)                                         | Atajo (macOS)                                                 |
| ----------------------------------- | --------------------------------------------------------------- | ------------------------------------------------------------- |
| **Guardar Snapshot**                | <kbd>Ctrl</kbd> + <kbd>S</kbd>                                  | <kbd>Cmd</kbd> + <kbd>S</kbd>                                 |
| **Ver Línea de Tiempo (Historial)** | <kbd>Ctrl</kbd> + <kbd>H</kbd>                                  | <kbd>Cmd</kbd> + <kbd>H</kbd>                                 |
| **Crear Nuevo Diagrama**            | <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>N</kbd>                 | <kbd>Cmd</kbd> + <kbd>Option</kbd> + <kbd>N</kbd>             |
| **Compartir Sala Colaborativa**     | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd>               | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd>              |
| **Abrir Modal de Ayuda Rápida**     | <kbd>F1</kbd> o <kbd>?</kbd>                                    | <kbd>F1</kbd> o <kbd>?</kbd>                                  |
| **Abrir Asistente de IA (Prompt)**  | <kbd>Ctrl</kbd> + <kbd>J</kbd> / <kbd>Ctrl</kbd> + <kbd>K</kbd> | <kbd>Cmd</kbd> + <kbd>J</kbd> / <kbd>Cmd</kbd> + <kbd>K</kbd> |

---

## 2. Edición y Manipulación de Clases

| Acción                               | Atajo                                                                      |
| ------------------------------------ | -------------------------------------------------------------------------- |
| **Editar Miembro Seleccionado**      | <kbd>Enter</kbd>                                                           |
| **Eliminar Elementos Seleccionados** | <kbd>Supr</kbd> o <kbd>Backspace</kbd>                                     |
| **Copiar Selección**                 | <kbd>Ctrl</kbd> + <kbd>C</kbd>                                             |
| **Cortar Selección**                 | <kbd>Ctrl</kbd> + <kbd>X</kbd>                                             |
| **Pegar Selección**                  | <kbd>Ctrl</kbd> + <kbd>V</kbd>                                             |
| **Duplicar Rápido**                  | <kbd>Ctrl</kbd> + <kbd>D</kbd>                                             |
| **Mover Nodo (Nudge fino)**          | Flechas de dirección (<kbd>←</kbd> <kbd>↑</kbd> <kbd>→</kbd> <kbd>↓</kbd>) |
| **Mover Nodo (Paso grande)**         | <kbd>Shift</kbd> + Flechas de dirección                                    |
| **Cancelar Edición / Deseleccionar** | <kbd>Esc</kbd>                                                             |

---

## 3. Selección y Navegación

| Acción                             | Atajo                                                  |
| ---------------------------------- | ------------------------------------------------------ |
| **Seleccionar Todo**               | <kbd>Ctrl</kbd> + <kbd>A</kbd>                         |
| **Deseleccionar Todo**             | <kbd>Ctrl</kbd> + <kbd>D</kbd> o clic en espacio vacío |
| **Selección Múltiple por Caja**    | <kbd>Shift</kbd> + Arrastrar sobre el canvas           |
| **Alternar Elemento en Selección** | <kbd>Shift</kbd> + Clic sobre el nodo                  |
| **Modo Selección Múltiple**        | <kbd>M</kbd>                                           |

---

## 4. Vista y Navegación en el Canvas

| Acción                                | Atajo / Gesto                                                  |
| ------------------------------------- | -------------------------------------------------------------- |
| **Panorámica (Desplazamiento)**       | Arrastrar con botón izquierdo o <kbd>Espacio</kbd> + Arrastrar |
| **Zoom Fluido**                       | <kbd>Ctrl</kbd> + Rueda del ratón (o pellizco táctil)          |
| **Acercar Zoom**                      | <kbd>Ctrl</kbd> + <kbd>+</kbd>                                 |
| **Alejar Zoom**                       | <kbd>Ctrl</kbd> + <kbd>-</kbd>                                 |
| **Restablecer Zoom (100%)**           | <kbd>Ctrl</kbd> + <kbd>0</kbd>                                 |
| **Ajustar Todo al Canvas (Fit View)** | <kbd>Shift</kbd> + <kbd>1</kbd>                                |
| **Zoom a la Selección**               | <kbd>Shift</kbd> + <kbd>2</kbd>                                |

---

## 5. Historial de Acciones

| Acción              | Atajo (Windows / Linux)                                                            | Atajo (macOS)                                    |
| ------------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------ |
| **Deshacer (Undo)** | <kbd>Ctrl</kbd> + <kbd>Z</kbd>                                                     | <kbd>Cmd</kbd> + <kbd>Z</kbd>                    |
| **Rehacer (Redo)**  | <kbd>Ctrl</kbd> + <kbd>Y</kbd> o <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Z</kbd> | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>Z</kbd> |
